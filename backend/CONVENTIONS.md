# Instruções para o assistente de programação aider
- Responda sempre em português brasileiro (pt-BR). 
- Explique o código, os erros e as soluções em português. 
- Escreva comentários no código em português. 
- Preserve nomes de classes, métodos, variáveis e APIs existentes. 
- Não altere arquivos quando o usuário solicitar apenas uma explicação. 
- Seja objetivo e evite respostas desnecessariamente longas.
- Antes de fazer alterações, entenda o código existente.
